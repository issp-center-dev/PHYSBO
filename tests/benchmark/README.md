# Benchmark scripts for multi-objective Bayesian optimization

This directory contains standalone scripts for benchmarking the
multi-objective search policies of PHYSBO. They measure how the volume of
the dominated region (hypervolume) grows with the number of Bayesian search
steps, and how much wall time the search takes.

These scripts are **not** unit tests: they are not collected by pytest
(no `test_*.py` naming) and are not executed in CI. Run them manually.

## Requirements

- `physbo` (this repository) and its dependencies
- `matplotlib` — imported unconditionally by `common.py`.
  Note that `matplotlib` is *not* included in the `tests` extra;
  install it separately, e.g. `pip install matplotlib`.

## Files

| File | Role |
| ---- | ---- |
| `common.py` | Shared logic: runs a benchmark for one parameter set (`benchmark()`), generates centers of the `Gaussian` test function (`gen_centers()`), and resolves experiment parameters such as score names and unifying methods (`set_parameters()`). |
| `functions.py` | CLI driver: benchmark a single named test function from `physbo.test_functions.multi_objective`. |
| `nobjs.py` | CLI driver: benchmark the `Gaussian` test function while varying the number of objectives, to study scaling with `nobj`. |

## Usage

### `functions.py`

Write the header line first (this truncates the output file), then append
one or more runs:

```bash
python functions.py --header --test_function VLMOP2
```

```bash
python functions.py --test_function VLMOP2 --score EI
```

Results are appended to `<output_dir>/<test_name>.txt` (default
`output_functions/VLMOP2.txt`), one line per completed search set.
Scatter plots of the Pareto front are saved as
`solutions_<test_name>_<score_name>_<num_bayes>.pdf` in the same directory.

Main options (see `--help` for the full list):

| Option | Default | Meaning |
| ------ | ------- | ------- |
| `--test_function` | `VLMOP2` | Class name in `physbo.test_functions.multi_objective` (e.g. `VLMOP2`, `BinhKorn`, `ZDT1`, `Kursawe`, `Gaussian`, ...) |
| `--Gaussian_dim`, `--Gaussian_nobj` | 2, 2 | Input dimension / number of objectives, used only with `--test_function Gaussian` |
| `--score` | `TS` | Acquisition function: `EI`, `PI`, or `TS` (see "Score names" below) |
| `--unify_method` | `None` | `None`, `ParEGO`, or `NDS` |
| `--num_random_search` | 10 | Number of initial random-search steps |
| `--num_bayes_search` | 10 | Number of Bayesian-search steps per set |
| `--num_bayes_search_set` | 4 | Number of sets; hypervolume is recorded after each set |
| `--nrand_basis_TS` | 300 | Number of random basis functions (used when `--score TS`) |
| `--N` | 51 | Grid points per dimension (dim ≤ 3), otherwise `N^3` random candidates |
| `--use_range` | off | Use the continuous (range) policies instead of the discrete ones |
| `--seed` | 12345 | Random seed |
| `--output_dir` | `output_functions` | Output directory |
| `--header` | off | Write the header line to the output file and exit |

### `nobjs.py`

Same idea, but the test function is fixed to `Gaussian` with centers
generated by `gen_centers()`, and the number of objectives is a parameter:

```bash
python nobjs.py --header --dim 2
```

```bash
python nobjs.py --nobj 3 --dim 2 --score TS
```

Results are appended to `<output_dir>/dim_<dim>.txt` (default
`output_nobjs/dim_2.txt`). PDF plots are produced only with `--savefig`.
`gen_centers()` supports `--dim 1` and `--dim 2` only.

## Score names

`set_parameters()` in `common.py` maps the `--score` option to the actual
acquisition function, depending on `--unify_method`:

- Without a unifying method (`--unify_method None`), the multi-objective
  scores are used: `EI` becomes `EHVI`, `PI` becomes `HVPI`, and `TS`
  stays `TS`.
- With `ParEGO` or `NDS`, the objectives are unified into a single one and
  the single-objective `EI` / `PI` / `TS` is used directly. The score name
  recorded in the output is prefixed, e.g. `ParEGO-EI`.
- `TS` uses a Bayesian linear model with `--nrand_basis_TS` random basis
  functions; for `EI`/`PI` the exact GP is used (`nrand_basis = 0`).

## Output format

Each line of the output text file contains four space-separated columns.
The second column differs between the two scripts:

```text
score num_bayes volume elapsed_time   # functions.py
score nobj      volume elapsed_time   # nobjs.py
```

- `score` — resolved score name (e.g. `EHVI`, `ParEGO-EI`).
- `num_bayes` (`functions.py`) — cumulative number of Bayesian-search
  steps at the end of the set.
- `nobj` (`nobjs.py`) — number of objectives.
- `volume` — volume of the dominated region measured against the test
  function's reference box (`reference_min`, `reference_max`).
- `elapsed_time` — wall time in seconds, **cumulative** since the start of
  the first Bayesian-search set (not per-set).
