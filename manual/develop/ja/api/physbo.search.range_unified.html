class physbo.search.range_unified.History(num_objectives, dim)[ソース]

ベースクラス: _RangeMultiHistory

The history of a search with unified objectives in a continuous search space (physbo.search.range_unified.Policy).

It records the objectives themselves, not the unified one. The observations are in fx (the objective values, one column per objective) and action_X (the inputs), with one row per observation (total_num_search of them). pareto is the Pareto front of the observations.

パラメータ:

  • num_objectives (int) -- The number of objectives.

  • dim (int) -- The dimension of the search space.

property action_X

The inputs of the observations (total_num_search x dim).

戻り値:

  • front_num (numpy.ndarray) -- The indexes of these observations in the history.

property valid_mask

Mask of valid observations (True) vs failed ones (False).

An observation is failed when its objective value (any of them, for several objectives) is not finite (NaN or +-Inf). Failed observations are kept in the history but excluded from the training data and from the best value so far or the Pareto front.

class physbo.search.range_unified.Policy(num_objectives, *, min_X=None, max_X=None, constraint=None, comm=None, config=None, initial_data=None, rng=None)[ソース]

ベースクラス: _UnifiedObjectiveMethods, Policy

Multi objective Bayesian optimization with continuous search space

パラメータ:

  • num_objectives (int) -- The number of objective functions.

  • min_X (numpy.ndarray) -- The minimum value of each dimension of the search space.

  • max_X (numpy.ndarray) -- The maximum value of each dimension of the search space.

  • constraint (callable, optional) -- Inequality constraints on the search space, as in physbo.search.range.Policy: a function from an array of shape (N, d) to a boolean array of N elements (True for feasible points). Only feasible points are proposed. Not saved by save(); pickled by save_checkpoint(), so it must be picklable.

  • comm (MPI.Comm, optional) -- MPI Communicator

  • config (SetConfig object (physbo.misc.SetConfig))

  • initial_data (tuple[np.ndarray, np.ndarray]) -- The initial training datasets. The first element is the array of inputs and the second is the array of values of the objective functions, of shape (N, num_objectives). These points are not checked against the constraint.

  • rng (None, "legacy", int, or numpy.random.Generator, optional) -- Random number generator specification (default: "legacy"). See physbo.search.discrete.Policy for details.

property L_X

The width of each dimension, max_X - min_X.

bayes_search(training_list=None, max_num_probes=None, num_search_each_probe=1, predictor=None, is_disp=True, disp_pareto_set=False, simulator=None, score='EI', unify_method=None, interval=0, num_rand_basis=None, optimizer=None, ard=None, ucb_beta=1.0)[ソース]

Performing Bayesian optimization by using unified objective function

パラメータ:

  • training_list (list of physbo.Variable, optional) -- The training datasets.

  • max_num_probes (int, optional) -- The maximum number of searching process by Bayesian optimization.

  • num_search_each_probe (int, optional) -- The number of searching by Bayesian optimization at each process.

  • predictor (predictor object, optional) -- The predictor object.

  • is_disp (bool, optional) -- If true, process messages are outputted.

  • disp_pareto_set (bool, optional) -- If true, Pareto set is displayed.

  • simulator (callable, optional) -- The simulator function.

  • score (str or callable) -- TS, EI, PI, UCB, or a callable called positionally as score(predictor, training, test) returning a numpy.ndarray of shape (test.X.shape[0],), with larger values preferred. Empty test data skips the callable. Under MPI, the callable evaluates local points and must not perform collective communication. training contains unified targets of shape (N, 1).

  • interval (int, optional) -- The interval number of learning the hyper parameter. If you set the negative value to interval, the hyper parameter learning is not performed. If you set zero to interval, the hyper parameter learning is performed only at the first step. A negative interval needs a learned predictor: the one learned by an earlier bayes_search, or one given as an argument, read by load() or set by hand. Otherwise, or if another kind of predictor is asked for (see num_rand_basis), a RuntimeError is raised.

  • num_rand_basis (int, optional) -- The number of basis function. If you choose 0, ordinary Gaussian process run. If None (default), the predictor the policy has is used, whatever its kind; a Gaussian process is made if it has none yet. The predictor is kept between calls of bayes_search. A new one is made, to be learned, when the predictor is not of the kind asked for by num_rand_basis or ard.

  • unify_method (callable) -- The unified objective function. It is a function or a callable object that maps a (N, num_objectives) numpy.ndarray of original objective functions to a (N, 1) numpy.ndarray of unified objective functions. See physbo.search.unify for examples.

  • optimizer (Optimizer object, optional) -- Optimizer object for optimizing the acquisition function. If None, the default optimizer is used.

  • ard (bool, optional) -- If True, use Automatic Relevance Determination (ARD) for the Gaussian kernel. If None (default), as in the predictor the policy has; without ARD if it has none yet.

  • ucb_beta (float) -- Trade-off parameter between exploitation and exploration used for string "UCB". The score is fmean + ucb_beta * fstd. Default is 1.0; ignored for callable scores.

戻り値:

history

戻り値の型:

history object (physbo.search.range_unified.History)

get_score(mode, *, xs=None, predictor=None, training=None, pareto=None, parallel=True, alpha=1, ucb_beta=1.0)[ソース]

Calculate score (acquisition function)

パラメータ:

  • mode (str or callable) -- TS, EI, PI, UCB, or a callable called positionally as mode(predictor, training, test) returning a numpy.ndarray of shape (test.X.shape[0],), with larger values preferred. Empty test data skips the callable but still participates in MPI gathering. The callable must not perform collective communication. alpha and ucb_beta apply only to string modes. training contains unified targets of shape (N, 1).

  • xs (physbo.Variable or np.ndarray) -- input parameters to calculate score

  • predictor (predictor object) -- predictor used to calculate score. If not given, self.predictor will be used.

  • training (physbo.Variable) -- Training dataset. If not given, self.training_unified will be used.

  • pareto (Pareto, optional) -- Retained for API compatibility; unused for unified scoring.

  • parallel (bool) -- Calculate scores in parallel by MPI (default: True)

  • alpha (float) -- Tuning parameter which is used if mode = TS. In TS, multi variation is tuned as np.random.multivariate_normal(mean, cov*alpha**2, size).

  • ucb_beta (float) -- Trade-off parameter between exploitation and exploration used for string "UCB". The score is fmean + ucb_beta * fstd. Default is 1.0; ignored for callable scores.

戻り値:

f -- Acquisition scores of shape (num_points,).

戻り値の型:

numpy.ndarray

例外:

RuntimeError -- If xs is not given

メモ

When parallel is True, it is assumed that the function receives the same input (xs) for all the ranks. If you want to split the input array itself, set parallel be False and merge results by yourself.

classmethod load_checkpoint(filename, comm=None)

Restore a policy from a checkpoint file.

Under MPI this is a collective operation: every rank must call it with the same filename; rank 0 reads the file and broadcasts it. The run must use the same number of MPI processes as the run that saved the checkpoint.

In the legacy RNG mode this restores the global numpy.random state of each rank as a side effect (the stream lives there); in the Generator mode the restored policy carries its own generator and the global state is not touched.

パラメータ:

  • filename (str) -- The name of the checkpoint file.

  • comm (MPI.Comm, optional) -- MPI communicator of the resuming run (default: None).

戻り値:

The restored policy, with comm attached.

戻り値の型:

policy

例外:

RuntimeError -- If the checkpoint was taken with a different policy class, a different number of MPI processes, or an incompatible checkpoint format.

save_checkpoint(filename)

Save the complete execution state into a single file.

Under MPI this is a collective operation: every rank must call it. The rank-local parts (remaining candidates and RNG state) are gathered, and rank 0 writes one file atomically (via a temporary file and os.replace).

In the legacy RNG mode the global numpy.random state of each rank is captured; in the Generator mode (rng= given to the policy) the policy-owned generators are stored.

パラメータ:

filename (str) -- The name of the checkpoint file.

参考

load_checkpoint

restores the state and resumes bit-exactly.

save

persists only the search results (portable across runs with different numbers of MPI processes).

write(X, t, time_total=None, time_update_predictor=None, time_get_action=None, time_run_simulator=None)[ソース]

Writing history (update history, not output to a file).

パラメータ:

  • X (numpy.ndarray) -- N x d dimensional matrix. Each row of X denotes the d-dimensional feature vector of each search candidate.

  • t (numpy.ndarray) -- N dimensional array (1D) or N x 1 dimensional array (2D). The negative energy of each search candidate (value of the objective function to be optimized). Will be normalized to (N, 1) shape internally. All the values must be finite. Failed evaluations are not supported in continuous search spaces.

  • time_total (numpy.ndarray) -- N dimenstional array. The total elapsed time in each step. If None (default), filled by 0.0.

  • time_update_predictor (numpy.ndarray) -- N dimenstional array. The elapsed time for updating predictor (e.g., learning hyperparemters) in each step. If None (default), filled by 0.0.

  • time_get_action (numpy.ndarray) -- N dimenstional array. The elapsed time for getting next action in each step. If None (default), filled by 0.0.

  • time_run_simulator (numpy.ndarray) -- N dimenstional array. The elapsed time for running the simulator in each step. If None (default), filled by 0.0.

例外:

ValueError -- If t contains a non-finite value (NaN or +-Inf). Nothing is written to the history in this case.
