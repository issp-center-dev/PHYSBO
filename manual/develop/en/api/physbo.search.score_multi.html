Thompson Sampling for multi-objective optimization.

Parameters:

  • training (Variable) – Training data containing all objectives.

  • test (Variable) – Test points.

  • alpha (float, optional) – Scaling parameter for sampling from posterior distribution. Default is 1.

  • reduced_candidate_num (int, optional) – Number of candidates to randomly select for Pareto front calculation. If None or less than number of test points, all points are used. Default is None.

physbo.search.score_multi.resolve(score, *, alpha=1.0, reduced_candidate_num=None, rng=None)[source]

Resolve a multi-objective score name or return a callable unchanged.

Parameters:

  • score (str or callable) – “EHVI”, “HVPI”, “TS”, or a callable accepting predictor_list, training, test and pareto as positional arguments.

  • alpha (float, optional) – Posterior sampling scale for “TS”. Default is 1.0.

  • reduced_candidate_num (int, optional) – Candidate limit for “TS”. Default is None, using all candidates.

  • rng (rng object, optional) – Random number generator for “TS”. A callable that holds a generator in an rng attribute and was not given one of its own (the built-in ThompsonSampling) is attached to it (see physbo._rng.attach_rng()). Default is None, the global numpy.random state.

Returns:

Acquisition function. Existing callables are returned unchanged.

Return type:

callable

Raises:

  • NotImplementedError – If the score name is unknown.

  • TypeError – If score is a class rather than an instance, or is neither a string nor a callable.

Calculate multi-objective acquisition scores for test data.

Parameters:

  • mode (str or callable) – “EHVI”, “HVPI”, “TS”, or a callable called as mode(predictor_list, training, test, pareto).

  • predictor_list (list of predictor objects) – Predictor for each objective.

  • test (physbo.Variable) – Test inputs.

  • training (physbo.Variable) – Training dataset containing all objectives.

  • pareto (Pareto) – Required for EHVI and HVPI. Passed to callable modes, as None when omitted.

  • alpha (float) – Posterior sampling scale for string “TS”. Default is 1.0.

  • reduced_candidate_num (int or None) – Required candidate limit for string “TS”; None uses all candidates. Callable modes ignore this parameter and alpha.

  • rng (rng object) – Random number generator for string “TS” (default: the global numpy.random state); a callable mode draws from its own.

Returns:

Acquisition scores of shape (test.X.shape[0],).

numpy.ndarray
